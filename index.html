The Forwarded-Email Problem

Claude returned empty commitment arrays on forwarded emails. The original message was buried inside nested quoted HTML and the extraction prompt could not reach it. This is the failure mode from the screening answer.

The Watchdog

A time-driven trigger runs every 30 minutes and checks the last N extractions. If ten consecutive emails return zero commitments, it sends an alert. Zero is the failure mode, not an error: the script runs, the API returns 200, the JSON parses, and the array is empty. Without the watchdog, nobody knows.

function watchdog() { const recent = getRecentExtractions(10); const allZero = recent.every(r => r.commitments.length === 0); if (allZero && recent.length === 10) { sendAlert({ type: "extraction_drift", message: "10 consecutive zero-commitment extractions", lastThreadIds: recent.map(r => r.threadId), suggestion: "Check for forwarded/nested HTML in recent threads" }); } }

One-Week Client Install — Template v2.4.1

Deployment checklist for a new Google Workspace client. Adjust for M365/Power Automate where noted. All hours are working hours; client sign-offs sit on top.

  1. Day 1 — Access + Discovery (3h)
    Get Workspace admin access, audit existing email rules and labels
    OAuth consent screen, domain verification, confirm which Gmail account the trigger runs as. For M365: app registration in Entra ID, mail.read + mail.send permissions.
  2. Day 2 — Deploy + Configure (4h)
    Deploy Apps Script project, configure Claude API key, set up triggers
    Time-driven trigger every 5 minutes. Set extraction prompt to match the client's vocabulary. Test against 20 recent emails from their inbox. Calibrate confidence threshold.
  3. Day 3 — Calibrate (3h)
    Review first 24h of extractions, tune prompt, add client-specific terms
    Expected: 60-70% accuracy on first pass. Adjust for their specific commitment language ("I'll get back to you" vs "we need to file by"). Set up the forwarding address for off-system commitments.
  4. Day 4 — Onboarding (2h)
    Team training: where tasks appear, how to log off-system commitments
    15-minute walkthrough with the team. Show them the forwarding rule (5 seconds to learn), the weekly review prompt, and where overdue items surface. Record a Loom for anyone who misses it.
  5. Day 5 — Verify + Handoff (3h)
    Run full extraction audit, deploy watchdog, document the install
    Compare system-extracted commitments against manually identified ones from the week. Target: 85%+ recall. Write the install back into the template. Hand off the health dashboard credentials.
